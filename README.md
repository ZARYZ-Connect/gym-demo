# IRONFORGE GYM — Modern Fitness & Gym Website Template

A ultra-premium, modern, dark-themed responsive website template designed for elite gyms, fitness studios, crossfit boxes, and personal trainers.

## 🌟 Features

- **Dynamic Dark Theme & Neon Accents**: Built with electric lime, blood red, and sleek dark surfaces.
- **Custom Interactive Cursor**: Smooth animated dot and ring follower.
- **Scroll Reveal Animations**: Micro-interactions and smooth section reveals.
- **Animated Counter Stats**: Highlighting active members, expert trainers, weekly classes, and satisfaction rate.
- **Continuous Marquee**: Endless scrolling ribbon featuring fitness specialties.
- **Program Showcase**: High-intensity training cards with hover effects.
- **Transformation Section**: Before/after highlight with key pillars.
- **Infinite Facility Gallery**: Auto-scrolling showcase of workout spaces and equipment.
- **Trainer Profiles**: Expert coaches with social links and experience badges.
- **Tiered Pricing Table**: Interactive membership options with highlighted popular choice.
- **Member Reviews**: Testimonials showing real transformation results.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop screens.

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom properties & modern flex/grid layouts)
- **Vanilla JavaScript** (IntersectionObserver, custom cursor, smooth scrolling)
- **Google Fonts** (Anton, Barlow Condensed, Outfit)
